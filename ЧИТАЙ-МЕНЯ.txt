CLIPVEIN — как запустить
========================

1. Двойной клик по файлу:  УСТАНОВИТЬ-И-ЗАПУСТИТЬ.bat

Он сам поставит Python (если его нет), сам поставит всё нужное
и сразу откроет приложение. Первый раз — пару минут.

Если после установки Python окно попросит запустить второй раз —
просто закрой его и снова кликни по УСТАНОВИТЬ-И-ЗАПУСТИТЬ.bat.

Внутри приложения:
  - слева выбери стримера
  - внизу переключи "source" на mock (демо без браузера) для проверки
  - нажми "Find clips"
  - справа появятся 3 ссылки

Чтобы читать живую ленту твиттера — оставь source = browser
и нажми "Connect browser" (откроется Chrome, войди там в X один раз).
